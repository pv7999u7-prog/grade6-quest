# 六年級闖關王（六上 社會康軒＋自然南一）

給孩子在 iPad 上用的學習遊戲，玩法和其他闖關王相同：每天完成社會和自然兩科挑戰，內含重點筆記。
不用上架，不用帳號，進度存在 iPad 本機（和其他闖關王分開存）。

## 內容來源
沒有講義，課次與重點依各校 114 學年度公開的課程計畫整理，內容以課本為準；拿到課本或講義後可以再補強。

## 檔案
| 檔案 | 用途 |
|---|---|
| `index.html` | 畫面與樣式 |
| `app.js` | 遊戲邏輯（和其他闖關王同一套程式） |
| `chapters.js` | App 設定、課次、期中／期末範圍、**重點筆記** |
| `questions.js` | **題庫** 155 題：社會 83 題（10 課＋主題）、自然 72 題（4 單元，含隨機情境題） |
| `dog.js` | 狗狗養成（黑四目長毛臘腸） |
| `write.js` | 共用的手寫模組（這個 App 沒有手寫題，不會出現） |
| `sw.js`、`manifest.webmanifest`、`icon-*.png` | 離線快取、主畫面圖示 |

## 範圍
- **期中考（預設）**：社會第一、二單元（1-1～2-2）＋自然第 1、2 單元
- **期末考**：社會第三、四單元＋主題探究＋自然第 3、4 單元
- **每次打開 App 都會先問「今天要練哪些章節？」**，可以一鍵選期中、期末或逐課勾選；首頁「🎯 練習範圍」也能隨時改。家長頁一樣可以設定。

## 出題與難度
- 沒寫過的題目優先；今天、昨天寫過的幾乎不會再出。
- 自動難度（★／★★／★★★）：看這一科最近 7 天的答對率，70% 以上混入「⭐ 進階」題（每回最多 3 題），85% 以上最多 5 題；家長頁「📈 自動難度」可看答對率。

## 每日任務與獎勵
社會挑戰、自然挑戰、讀一篇重點、複習錯題；兩個挑戰都完成才算打卡。每天最多 100 金幣；獎勵價格家長頁可改；孩子申請兌換 → 家長按「兌換」才扣金幣。

## 🐶 狗狗養成
黑四目長毛臘腸，六個成長階段（新生小奶狗 → 傳說神犬），每週成長上限 330，目標 1/10 期末考前養成；商店有毛色、帽子、衣服、叼的東西、坐騎、背景。

## 加入 iPad 主畫面
用 **Safari** 開啟網址 → 分享 ⬆️ →「加入主畫面」。家長密碼預設 **0000**。

## 新增題目
在 `questions.js` 照格式加（X 選擇、T 是非、O 排序；lv: 2 是進階題）。更新後把 `sw.js` 的 `VERSION` 改一下（例如 `g6q-v2`），iPad 才會抓到新版。
